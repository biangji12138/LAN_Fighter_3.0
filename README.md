# LAN Fighter 3.0 — 融合型火柴人格斗（角色 / 连招版）

> 基于 LAN Fighter 2.0 重构，Pygame 菜单、单人 AI、技能训练、电脑双人对战（AI 观战）、局域网双人房间、音效、设置和三局两胜均保留。内置三张可选地图（原初战场 / 熔岩地貌 / 冰雪溶洞），三张地图都附带一张内置背景图，可自行替换；其余图片资源均为可选，也可选放入背景图与角色图，游戏会自动加载。**3.0 与 2.0 网络协议不兼容**，两台电脑都要使用 3.0。

## 快速启动（Windows）

1. 安装 Python 3.10+，进入本目录双击 `start_windows.bat`，或者在项目目录运行：
   ```powershell
   python -m pip install -r requirements.txt
   python main.py
   ```
   若使用项目内的虚拟环境，请用 `.venv\Scripts\python.exe main.py`。运行时唯一依赖是 pygame 2.5+（打包脚本会自动额外安装 PyInstaller 6.x）。
2. 单机：主菜单左右两个火柴人分别是 P1 与人机对手的角色，点击它们即可直接更换；随后点“对战 AI”或“技能训练”立即开局；点“AI 对打”则由两个 AI 自动对打，适合观战。选角均不再进入选角页。主菜单右下角的「地图」按钮可打开地图选择面板，在三张地图之间切换，选择会立即写入设置并用于之后的对局。面对 AI 的难度在**设置页**「AI 难度与角色风格」区的芯片里点选，AI 对打的左右两侧档位则在右侧 P2 角色卡上方两枚芯片里直接点选。
3. 选角页：角色卡只展示上半身与角色名，单击卡片选择角色，双击卡片进入角色展示页（左侧全身图，右侧名字 / 性别 / 身份 / 血量 / 小技能 / 大招 / 专属连招，并以按键胶囊标出大招与专属连招的按键顺序）。
4. 每回合开始前有 3 秒 `ROUND n` 倒数（连招训练不倒数，进入即练），倒数期间双方与回合时钟冻结，归零后显示 `FIGHT!` 并开始行动；回合结束时能量会保留到下一回合，血量则在下一回合回满。每回合限时 65 秒，时间耗尽按剩余血量判定，血量相同则该回合无人得分；先赢 2 回合者获胜（三局两胜），回合之间约 2.4 秒展示 K.O. 横幅，比赛结束约 7 秒后回到主菜单。
5. 技能训练：AI 不移动、不攻击，并且每帧自动回满血，适合反复练习单招与连段。左下角常驻**帧数据面板**，实时显示上一招的名称、起手 / 有效 / 收招帧、命中与格挡帧优势，以及当前所处的阶段、剩余帧数与取消窗口剩余帧（含空中挥空取消），方便对照手感逐帧调参。
6. AI 对打：双方角色都由 AI 操作，AI 会使用角色连招并在能量足够时释放大招；没有玩家输入，按 ESC 暂停，按 R 随时重开一局，可用来观战或对比角色强度。左右两侧的难度档位在主菜单右侧 P2 角色卡上方各有一枚芯片，点一下前进一档，可以一边困难一边普通。
7. 联机：电脑 A 选择“双人对抗 > 创建房间”；电脑 B 选择“加入房间”，输入 A 的 `ipconfig` 中 IPv4 地址；进入房间后各自点“选择角色”只为自己选择角色，双方准备后房主开始。
8. 如果无法加入，检查双方是否在可互访的局域网、Windows 防火墙是否放行该游戏，以及端口是否一致（默认 50007）。校园网可能禁止终端互访。
9. EXE：运行 `build_exe_windows.bat`，生成 `dist/LANFighter/LANFighter.exe`，两台电脑使用相同的 3.0 EXE。打包必须在 Windows 上完成。
10. **打包 EXE（详细步骤）**
   - 双击项目根目录的 `build_exe_windows.bat`；在 PowerShell 中需写成 `.\build_exe_windows.bat`（PowerShell 默认不从当前目录加载命令）。
   - 脚本会自动安装依赖（`requirements.txt` + PyInstaller 6.x），并以 `--onedir` 模式打包，同时把 `assets/` 一起带上（其中的 `assets/fonts/simhei.ttf` 用于在缺少中文字体的电脑上兜底显示）。
   - 产物为 `dist/LANFighter/`，可执行文件是 `dist/LANFighter/LANFighter.exe`，依赖在 `dist/LANFighter/_internal/`。**分发时必须整个 `dist/LANFighter/` 文件夹一起发**，只发单个 exe 无法运行。
   - 直接用打包产物运行时会弹出启动失败对话框，便于在别的电脑上排查缺失模块等问题。
11. **制作安装包（Setup.exe）**
   - 先完成第 10 步（`dist/LANFighter/` 必须存在），并确认 `redist/vc_redist.x64.exe` 存在（用于在纯净系统上自动安装 VC++ 2015-2022 运行库）。
   - 安装 [Inno Setup](https://jrsoftware.org/isinfo.php)，用其中的 Compiler 打开项目根目录的 `setup.iss`，直接点 Compile；也可以在命令行编译：
     ```powershell
     & "D:\Inno Setup 7\ISCC.exe" "setup.iss"
     ```
   - 产物为 `installer/LANFighter_Setup_v3.0.exe`，约 47 MB。发给别人只需要这一个文件，对方一路“下一步”即可完成安装（会显示安装目录页、创建桌面与开始菜单快捷方式、可卸载）。
   - 安装时会静默安装内置的 VC++ 运行库；卸载入口在开始菜单的 `LAN Fighter` 文件夹中。

## 地图

在地图选择面板（主菜单右下角「地图」按钮）中切换，选择会写入 `settings.json` 的 `map` 键。联机对局以**房主**选择的地图为权威，房主的地图 id 会随战斗快照同步给客户端，因此两端永远渲染同一张舞台。

| id | 名称 | 场地机制 |
| --- | --- | --- |
| `dojo` | 原初战场 | 经典无机关擂台，保留原有霓虹道场场景与配色 |
| `lava` | 熔岩地貌 | 地面每隔 5~15 秒在随机区域喷出火柱：预警 0.9 秒后喷发，范围约两人宽（半径 70 像素）、一人高（170 像素），中心预警圈内站立的角色受到 20 点伤害并短暂僵直；跳到柱顶以上、倒地或处于冰千年杀遁地状态时可躲开 |
| `ice` | 冰雪溶洞 | 洞顶每隔 2.4~5 秒随机掉下一人大小的冰棱，**没有任何预警**、以 1500 像素/秒极速下坠，砸中后原地冰冻 1 秒（不能移动、出招、跳跃），落地碎裂并伴随冰屑；看到落影后横向走开即可躲过，起跳越过冰棱也能避开 |

熔岩地貌的背景图位于 `assets/backgrounds/lava.jpg`（已提供一张动画风火山熔岩占位图），冰雪溶洞的位于 `assets/backgrounds/ice.jpg`，直接替换同名文件即可换背景。两张地图都有专属场地音效：火柱在预警圈亮起时播放一声嘶鸣、喷发瞬间是独立的低沉爆燃声；冰棱破空时有一声极短的风切声，命中与落地碎裂各有独立音效，均随「游戏音效」开关生效。新增地图只需在 `fighter/arena.py` 的 `MAPS` 中加一条数据，并在 `fighter/combat.py` 的 `_tick_map_hazards` 里给对应的 `map_id` 接上机关即可。

## 角色

以下资料以 `fighter/characters.py` 的 `CHARACTERS` 定义为准。

### 愤怒的普通人（红头巾 · `red_scarf`）

- 身份：烈焰拳师 · 性别：男
- 简介：省下愤怒的时间去愤怒，愤怒越多，愤怒越少。
- 血量 1000 · 移动速度 300 · 外观：红色围巾 / 红色点缀
- 远程「火焰弹」：14 伤害，420 速度，0.8 秒存活
- 大招「拿来吧你」：`S S J K`，拉取 300 范围内对手，按自身已损失血量打 4~10 段 × 40 伤害（满血 4 段共 160，最多 10 段共 400），随后甩飞半个地图距离并击倒 2 秒
- 专属连招「素质三连」：`S S U`，能耗 25，下三次攻击每次额外 50 伤害，第三次追加一发火焰弹

### 冷静的普通人（蓝头巾 · `blue_headband`）

- 身份：寒霜游侠 · 性别：男
- 简介：人非圣贤，要心如止水，就得先打！。
- 血量 800 · 移动速度 340 · 外观：蓝色头带 / 蓝色点缀
- 远程「冰手里剑」：11 伤害，1350 速度，0.25 秒存活（射程约 338），向前发射一枚旋转的十字冰制手里剑
- 大招「霜影奔袭」：先双击 `A` 或 `D`（`A A J J` / `D D J J`），再连按两次 `J`，突进 260 像素，5 段斩击共 150 伤害（每段 30）
- 专属连招「冰千年杀」：`S S` 移动键 `J`，能耗 30，遁入地下消失，1 秒后瞬移至敌人脚下冲出并击飞，造成 70 伤害

### 张扬的普通人（黄披风 · `yellow_cape`）

- 身份：奔雷浪客 · 性别：男
- 简介：杨村第一懒洋洋，我不张扬谁张扬。
- 血量 850 · 移动速度 400 · 外观：黄色披风 / 金色点缀
- 远程「雷弧」：3 伤害，3375 速度（原 2.5 倍），0.18 秒存活（射程约 600，原 3 倍），金色电鞭
- 大招「雷霆嘎巴」：双击 `A` 或 `D`（两个方向都有效）→ `J J`，先向前冲刺 180 像素，再击飞对手 250 伤害；对手在空中时再被强化落雷命中 100，随后坠地（动画帧加长到约 1.8 秒，冲刺 / 抬手 / 收招更清晰）
- 专属连招「打雷」：`S S U`，能耗 30，在敌人脚下生成两人大的黄圈，1 秒后落雷砸下造成 75 伤害（可走位离开黄圈躲避）

### 上班的普通人（灰领带 · `gray_tie`）

- 身份：通勤打工人 · 性别：男
- 简介：我只是一个平平无奇的上班族，请不要来打扰我。
- 血量 1100 · 移动速度 280 · 外观：土黄色调 / 灰色领带
- 远程「让开！」：4 伤害 / 段，速度 100，1.6 秒存活（最远推进约 160 像素）；命中不消失，推着敌人前行并每 0.25 秒结算一段伤害；退开或起跳可脱离，被推到场地边缘追加 8 伤害并短暂倒地
- 大招「借过一下」：`S S` + 方向键 + `I`，能耗 100，霸体向前冲锋 340 像素（期间免疫硬直/击退但仍受伤害），撞到人后先造成 40 伤害，再勾脖摔地造成 110 伤害，共 150；敌人倒地 2 秒，自己立即起身
- 专属连招「晚高峰警告」：`S S L`，能耗 40，附加 200 点护盾持续 7 秒，受击先扣护盾（护盾不挡硬直），到点或被打空后消散

### 迪奥布兰达（外号吸血鬼 · `dio`）

- 身份：吸血鬼 · 性别：男
- 简介：人类的能力是有极限的……除非超越人类。
- 血量 900 · 移动速度 300 · 外观：黄色竖发 / 黄色外套与长裤 / 血红双眼
- 远程「飞刀」：按 `U` 掷出一把银色飞刀，10 伤害，速度 720、存活 0.9 秒（射程约 648），瞬发；站立投掷走高位弹道，`S + U` 从低位掷出可以打到蹲着的对手；飞刀命中即消失，可以被蹲下躲开
- 大招「砸瓦鲁多」：`S S L L`（双击 S 后再双击 L），能耗 100，零帧起手（按下指令的下一帧立即生效，没有可被打断的前摇）后全场时间停止 7 秒；时停期间对手、投射物、落雷、场地机关与回合计时器全部定格，迪奥移速翻倍并可自由移动 / 冲刺 / 二段跳，只能用三个键行动：`J` 瞬发拳（每拳 8 伤害，不占前后摇，出拳手速就是输出上限）、`U` 掏飞刀（最多 8 把悬停空中，时间恢复瞬间齐射）、`K` 压路机收尾（需先用 J 打中 5 拳）；受击方只掉血并正常获得受击能量，不累积硬直、不被击飞；时停内把对手血量打空会立即结束时停并判胜
- 专属连招「气化冷冻法」：`A/D + L L`，能耗 30（命中返还一半 15 点，空放照扣），向前射出一段蓝色冰束（起手 14 帧、收招 20 帧；冰束飞行 0.42 秒，从身前约 62 像素射出，实际起手距离约 480 像素），命中造成 12 冻伤并冻住对手 1.5 秒；冻结期间对手无法移动 / 出招 / 跳跃，吃到第一记干净命中时额外承受 30 点「碎裂」伤害并提前破冰。冰束是飞行道具：站立防御能挡下（只吃 1/5 擦伤、不冻结），蹲下可以从下方让过去。命中后剩 85 点能量，还差 15 点才能开大——冻结窗口用来压血 / 走位，不是白送一次时停

角色配置集中在 `fighter/characters.py` 的 `CHARACTERS` 字典中：`health`（血量）、`move_speed`（移动速度，单位像素/秒）、`projectile`（小技能）、`super`（大招）、`super_command` / `super_radius` / `super_kind` / `super_distance` / `super_throw`（大招指令、范围与甩飞距离）、`buff` / `combo`（专属连招）全部按角色独立定义，战斗核心通过 `Combat.set_loadout()` 读取，新增角色无需改动战斗逻辑。移动速度直接决定走路快慢，并按同一比例影响冲刺与后撤。

| 按键 | 作用 |
| --- | --- |
| A / D | 左右移动 |
| W / 空格 | 跳跃（空中再按一次可二段跳） |
| S | 下蹲 |
| L | 站立防御（格挡减伤；挡不住蹲拳 / 下踢 / 低位发波等下蹲系攻击） |
| J | 轻拳（9 伤害，起手 4 帧、收招 8 帧） |
| K | 轻脚（15 伤害，起手 8 帧、收招 13 帧） |
| I | 抓取（12 伤害，不可格挡；命中后对手约 1.2 秒无法行动） |
| U | 远程攻击（不耗能量，招式随角色变化） |
| 长按 U | 迪奥布兰达的「飞刀」按一次掷出一把（按住不放只出一把，需连续点按）；`S + U` 从低位掷出 |
| S + U | 下蹲发波（从低位发射，站立发波从颈肩高度发射） |
| S + J | 蹲拳（下蹲出拳，8 伤害） |
| S + K | 下踢（下蹲出脚，12 伤害，攻击对手下段） |
| S + I | 蹲下抓取 |
| S + L | 蹲防（下蹲格挡；除抓取 / 蹲下抓取外全部可挡，高波会从头顶飞过） |
| 空中 J | 空中拳（跳跃状态下出拳，11 伤害） |
| 双击 A / D | 冲刺：前冲 10 帧 / 后撤 8 帧（拳皇式双击方向） |
| S S U | 愤怒的普通人的专属连招「素质三连」：消耗 25 能量点燃双拳，下三次攻击每次额外 50 伤害，第三次攻击还会朝攻击方向追加一发火焰弹 |
| `S S` 移动键 `J` | 冷静的普通人的专属连招「冰千年杀」：消耗 30 能量遁入地下消失，1 秒后瞬移至敌人脚下冲出并击飞（造成 70 伤害） |
| 双击 A / D 接 J J | 冷静的普通人的大招「霜影奔袭」：先双击 `A` 或 `D`（两个方向都有效），再快速按两次 J（能量达到 100 时）；朝面朝方向突进 260 像素，对手在范围内则闪到其身后连斩 5 次（每次 30，共 150 伤害） |
| S S J K | 愤怒的普通人的大招「拿来吧你」：先快速轻点两次 S，再按 J + K（6 帧内）；把 300 范围（原范围两倍）内的对手吸到面前控制住，按施法者已损失血量打 4~10 段拳击（每段 40，最高 400），随后甩飞半个地图距离（464 像素）并击倒 2 秒；范围外整招落空 |
| S S L L | 迪奥布兰达的大招「砸瓦鲁多」：快速点两次 S 再点两次防御键 L（能量达到 100 时），零帧起手，按下指令的下一帧立即全场时停 7 秒 |
| 时停中 J / U / K | 迪奥专属：`J` 瞬发拳（连打成 MUDA 连打）、`U` 掏飞刀悬停（最多 8 把，时间恢复时齐射）、`K` 压路机终结（需先打中 5 拳，砸下即恢复时间） |
| A/D + L L | 迪奥布兰达的专属连招「气化冷冻法」：先点一下移动方向，再快速点两次 L，消耗 30 能量向前射出一段蓝色冰束（约 480 像素），12 冻伤并把对手冻住 1.5 秒；冻结中打中他的第一击额外 30 点碎裂伤害并提前破冰。冰束是飞行道具，站着防御只吃擦伤、蹲下可以躲过；命中的那次返还一半能耗（15 点），满能量打完剩 85，还要再攒 15 点才能开大 |
| ESC | 战斗中暂停 / 退出当前界面 |
| R | 练习 / 技能训练中重新开始 |

游戏内“设置 > 查看招式表”只展示通用按键与连招；角色专属大招和专属连招的按键顺序在角色展示页（双击角色卡进入）中展示。对战中按 ESC 暂停后，暂停面板上的「招式表」按钮会直接打开**当前角色**招式表：小技能 / 大招 / 专属连招的名称、按键、伤害与能耗，外加通用按键速查，看完点「返回对战」回到暂停中的对局。

## 手柄（可选，插上即用）

标准 SDL2 手柄（Xbox / PlayStation / Switch Pro 等）无需安装额外依赖，pygame 2.5+ 自带映射；启动后插入也会在下一帧自动接管。战斗中输入与键盘**按位或合并**，两种设备可随时切换；菜单与设置页用手柄推动虚拟光标，确认键等价于鼠标左键，返回键与 Start / Back 等价于 ESC。设置页「音频 · 画面 · 手柄」区的「手柄操作」开关可整体关闭手柄（默认开启）。

| 手柄 | 作用 |
| --- | --- |
| 左摇杆 / 十字键 | 移动、下蹲（↓+攻击即下蹲技）、跳跃（↑） |
| A（南键） | 跳跃（菜单中的确认键） |
| X（西键） | 轻拳 J |
| Y（北键） | 轻脚 K |
| B（东键） | 远程攻击 U（菜单中的返回键） |
| RB 右肩键 | 抓取 I |
| LB 左肩键 / RT 右扳机 | 防御 L（↓+防御即蹲防） |
| Start / Back | 暂停 / 返回（等同 ESC） |

双击方向冲刺、`S S` 系列连招等指令依旧由手柄方向与按键的按下边沿解析，连招与键盘完全一致。极少数没有 SDL2 内置映射的杂牌手柄可能无法识别，可用 SDL 手柄映射工具补一条 mapping。


主菜单右侧 **P2 角色卡上方**挂着两枚**难度芯片**（如「左 普通」「右 地狱」，点一下在四档里前进一档），它们是观战「AI 对打」时左右两侧 AI 的档位，可以一边困难一边普通；面对 AI 的对手档位则在**设置页**「AI 难度与角色风格」区点击芯片选择（弹出四档小浮层，点面板外或按 ESC 关闭）。难度沿用《街霸 6》“先加战术、再加执行”的思路：**普通**按对手血量切换打法（对手血量高时以远程弹幕牵制，血量低时主动压上打连招）；**中等**不再看血量，而是自行判断局面（惩罚硬直 / 挥空、对手举盾时贴身抓取或下段、能量足够时逼近放大招、自己残血时拉开距离）；**困难**在中等基础上反应更快、更善于闪避弹幕，并只要能量足够、对手已进入大招命中范围就立刻释放大招；**地狱**在人类判断之上叠加全知全能的读帧能力——对手抓取一起手就后撤、攻击挥空期间前压、收招帧当帧反打，且闪避、放大招、投弹概率全部拉满，绝不失误。所有档位都会识别“机械连打节奏”：最近几次近战出招挤在短窗口内（单键连打正是这种节奏）时，AI 不等反应延迟、按难度概率提前举盾迎击——普通档 15%、中等 45%、困难 70%、地狱 90%；预判举出的盾仍会被投技与下段踢破解，变节奏、骗招与投技是打开它的正解。所有档位还会抓住**恢复帧窗口反击**（确反概率：普通 10%、中等 30%、困难 55%、地狱 100%）：对手处于收招帧且在近身射程内时，AI 不再走位观望而是直接插最快一拳——连段疲劳的疲惫挥击与硬直衰减后的空档都会被它兑现。

设置页另有**角色专属风格**开关（默认开启）：难度决定“打得多好”，风格决定“打得像谁”。开启后每个角色按自己的优势距离带与习惯作战——烈焰拳师中距离控场且爱贴身抓取、寒霜游侠高速冲脸少扔弹幕、奔雷浪客拉开到最远距离用超远程雷弧牵制、上班的普通人中距离用推人墙压墙角并靠霸体冲锋找机会；关闭后所有角色走同一套通用难度 AI。风格与难度一样属于**开赛参数**：只在下一局生效，对局中途切换不会立刻改变这只 AI 的打法。

同一页面还可修改**默认玩家昵称**（最多 12 字符，联机房间中显示）、**默认服务器 IP** 与**默认连接端口**（1024–65535，默认 50007），并切换**背景音乐**、**游戏音效**与**全屏模式**。背景音乐按地图播放：战斗页面循环播放 `assets/music/<地图id>.ogg` 或 `.wav`（OGG 优先，找不到时回退同名 WAV；原初战场 `dojo.ogg`、熔岩地貌 `lava.wav`——内置一段程序合成的熔岩战斗主题，152 BPM / D 小调 / 8 小节无缝循环；冰雪溶洞 `ice.wav`——132 BPM / A 小调的冰晶主题，同名替换即可换曲），菜单页静音，文件缺失时静默无音乐；开关实时生效。全屏不再使用 `pygame.SCALED`（它在部分 Windows 显卡上重复切换不生效），而是直接申请桌面分辨率的原生全屏，每帧把 1210×680 逻辑画布等比缩放上屏（16:9 桌面几乎满屏无黑边；16:10 等其他比例按等比缩放留背景色黑边，无拉伸变形），鼠标坐标按缩放比换算回逻辑坐标。所有设置即时保存：开关与难度芯片点击后立刻写入配置文件，文本字段在失去焦点（点击其他位置 / 回车 / 返回）时自动提交，「保存设置」按钮负责带提示的完整校验与提交。**难度是开赛参数**：芯片改动只在下一局生效，开局时按本局档位锁定，对局中途（含暂停→设置）改设置不会改变 AI 行为，HUD 上的 AI 名字也读锁定值，因此名字与实际难度永远一致；角色风格开关与难度同时在开局快照（`lock_match_ai`）。AI 对打的两侧档位分开保存在 `ai_level_p1` / `ai_level_p2`，旧存档缺这两个键时两侧沿用原来的 `ai_level`。设置页显示当前档位的芯片、主菜单 P2 卡上方的两枚直选芯片都只是在改下一次开局的参数，暂停进设置也不会临时换掉正在打的 AI。配置写入 `%APPDATA%\LANFighter\settings.json`（非 Windows 平台为 `~/.config/LANFighter/settings.json`），下次启动自动加载；没有存档时使用默认值，存档损坏或不可读会向 stderr 输出警告并回退默认值。

## 连招与演出

- **命中取消与输入缓存**：空挥（没有命中也没有被格挡）必须完整播放「起手 → 有效 → 收招」。一旦招式命中或被格挡，会开启一个取消窗口（轻拳 7 帧、轻脚 7 帧、下踢 6 帧、蹲拳 / 空中拳 5 帧），窗口内按下的下一招会跳过剩余收招立即衔接。每套连段最多取消 3 次，用完后必须等收招自然结束，且普通出招不会重置取消计数——只有挥空（招式全程未命中）、被对手击中或倒地才会重新计满，因此连按攻击键无法刷出无限取消连打；攻击期间提前按下的按键会进入**最多 3 招的预输入队列**，按输入顺序依次接上（不再互相覆盖；超过 45 帧仍未轮到则自动作废，被击中或倒地会清空整条队列）。键盘 / 手柄输入还带 **8 帧输入缓冲**：硬直或收招结束前几帧按下的攻击键，会在恢复可行动的第一时间自动生效；同一帧内先后按下的多个攻击键也不会互相覆盖，未被采用的键留在缓冲里，下一帧继续接上（用后即消费，不会凭空重复出招）。战斗输入同时用 `KEYDOWN` 事件补记按下沿，短于一帧的快速点按不会被逐帧采样漏掉。取消额度用尽后还会进入**连段疲劳**：此时打出的普通拳脚收招延长 6 帧，成为破绽巨大的疲惫挥击，正好留给对手的确反窗口（抓取与大招不吃疲劳）。**方向也随按键一起缓存**：蹲着按下 `J` / `K` / `U` 后，即使收招结束前已经站起来，接上的仍是蹲拳 / 下踢 / 低位发波，而不是站招；同一帧松开 `S` 的同时按下攻击键，还额外给 4 帧宽容，仍按蹲招判定。
- **抓取（I）**：近距离不可格挡，命中造成 12 伤害并令对手约 1.2 秒失去行动能力，便于后续追打；已处于长硬直的对手不能被连续抓取，避免无限循环。
- **受击僵直与倒地**：任何命中都会让受击者短暂僵直；短时间内连续受击会把僵直值累积到阈值，受击者被打倒在地至少 2 秒。同一套连段从第 3 段命中起，受击僵直按连段递减系数（70% / 55% / 40% / 30%）同步缩短，长连段无法把对手锁死在永久硬直里（大招与抓取的固定控制时长不受影响）。倒地期间完全免疫攻击（飞行道具会从身上飞过），计时结束后仍保持倒地，直到该玩家按下任意移动或攻击指令才立刻起身；起身瞬间另有 18 帧（0.3 秒）起身保护，期间免疫一切攻击，倒地真正成为攻防节奏的重置点，贴脸压起身会全部挥空。
- **防御架势**：站立防御挡不住任何下蹲系攻击（蹲拳、下踢、低位发波）；蹲防除抓取与蹲下抓取外全部可挡，因此低段攻击必须蹲防。抓取类招式无视两种防御。近战招式被格挡时，防御者会把攻击者向后推开一小段距离（格挡反推），举盾能真正换来喘息空间，贴脸磨盾不再是稳赚买卖。
- **下蹲闪避远程攻击**：下蹲（无论是否防御）时，站立发射的高位弹道会从头顶飞过而不判定命中；但如果波动飞到面前时站起来，就会按当前站姿吃满伤害（真人快打式判定）。低位发波仍会命中下蹲者，只有蹲防能减伤。
- **双键基础技**：`S + J` 蹲拳、`S + K` 下踢、`S + U` 下蹲发波、`S + L` 蹲防、`S + I` 蹲抓属于基础招式与防御姿态，不再作为连招统计；复杂多键连招将在后续版本基于这些基础动作设计。
- **大招**：消耗 100 能量触发，伤害、指令、范围、击飞与名称均按角色单独配置。冷静的普通人为方向指令技 `D D J J` 或 `A A J J`（先双击方向键，再连按两次 J），朝面朝方向突进 260 像素；若对手在突进距离内，会先闪到对手身后回身连斩 5 段（每段 30，共 150 伤害）。愤怒的普通人为指令技 `S S J K`（快速轻点两次下蹲键，再在 6 帧内按 J + K）：对手在自身 300 像素（原范围两倍）内时会被吸到面前并锁住，拳头连打 4~10 段，每段 40 伤害，段数随施法者损失的血量增加（每掉 15% 血量多一段，满血 4 段、最多 10 段共 400）；打完后把对手甩出半个地图距离（464 像素）并击倒 2 秒，范围外则整招落空。大招本身不可取消，必须完整播放前后摇；普通技命中或格挡后，可以在取消窗口内直接接大招（会跳过剩余收招），攻击中提前输入的指令则会在收招后衔接，带屏幕闪光、震屏与金色爆发粒子。**大招命中不再为施放者回复能量。**
- **帧数据**：每招有独立的命中 / 格挡硬直。轻拳命中 +8、格挡 -1；轻脚 +6 / -4；下踢 +3 / -8；蹲拳 +4 / -4；空中拳 +2 / -6。正数表示你先恢复行动，负数表示收招期间会被对手惩罚（例如下踢被格挡后留下约 8 帧的惩罚窗口）。
- **打击停顿**：命中瞬间双方一起定格固定帧数（轻拳/轻脚 2~3 帧、重招 4~6 帧、格挡 2 帧），让每一击有“咬合感”。帧数以 tick 计而不是按秒，本地与联机表现一致；停顿期间仍会记录输入，解冻后第一时间接上。
- **空中挥空取消**：跳跃普通技（空中拳）即使**没打中**，进入收招的瞬间也会开一个 4 帧的短取消窗口，此时按远程键 `U` 可直接取消成空中发波，不必等跳跃拳的整段收招落地。这是《真人快打》式的挥空取消：跳入压制被对手躲开时，仍能立刻补一发弹幕或改变节奏；打中了则不触发该窗口（命中走普通命中取消）。与 8 帧输入缓冲配合，在取消窗口前几帧按下的 `U` 也会在窗口开启时立刻生效。
- **Negative Edge（松键出招）**：松开攻击键同样算一次输入。按住 `U` 一段时间再松手，会在松开的瞬间放出特殊技 / 发波；松掉 `J` / `K` / `I` 也能补完大招与指令连招的按钮要求，让“先按住、再松手”成为有效的输入节奏。已经用来出过招的那次按下会在松开时被屏蔽，所以一次点按绝不会变成“按下一下 + 松开一下”两次出招；跳跃与防御是方向 / 姿态，不参与松键触发出招。配合输入缓冲，在硬直或前摇里按住不放，恢复可行动后松手就能接上。
- **连段递减与推离**：同一套连段里第 2 击伤害按 85% 结算，之后依次为 70% / 55% / 40% / 30%，最低 1 点；超过 65 帧没有新命中就重新按满伤害计算。同时每一段的推离距离逐级放大（每段 +25%，最多 +100%），长连段会自然把对手推出射程，避免无限循环。大招伤害不吃递减；格挡伤害固定为正常伤害的 1/5，且被格挡的命中不计入连段、会直接把连段计数清零，之后的命中重新按满伤害计算。远程弹幕与落雷目前不参与连段递减。
- **能量获取**：近战命中时攻击者 +10、远程命中 +8；大招命中不回能。受到伤害的一方获得对应回能的一半（近战 +5、远程 +4），因此劣势方也能靠挨打积攒反击能量。能量上限 150，回合结束时保留到下一回合。
- **素质三连（愤怒的普通人）**：`S S U`（快速轻点两次下蹲键，再按远程键）消耗 25 能量进入燃烧架势，双拳会持续冒出火焰；此后下三次命中的近战攻击每次附带 50 点额外伤害（轻拳 9+50、轻脚 15+50，蹲拳 / 下踢同理），第三次命中还会朝攻击方向追加一发火焰弹，用完后火焰熄灭。冰手里剑（冷静的普通人）改为速度极快、边旋转边前飞的十字冰制手里剑，射程保持原来的约 338 像素，站立/下蹲分别从颈肩与低位发射。
- **冰千年杀（冷静的普通人）**：`S S` 移动键 `J`（快速轻点两次下蹲键，再点一下移动方向并按 J）消耗 30 能量进入 12 帧钻地前摇后遁入地下消失；随后潜行 1 秒（期间无敌且不可被近战 / 投射物命中），接着瞬移至敌人脚下钻出、升到约一个半人高并命中，造成 70 伤害与小幅浮空，最后落地复位。整段前后摇约 1.7 秒，可被对手用拉开距离等方式迂回。
- **砸瓦鲁多（迪奥布兰达）**：`S S L L` 消耗 100 能量，零帧起手——按下指令的下一帧立即令全场时间停止 7 秒：对手、飞行道具、落雷、场地机关与回合计时器全部定格；迪奥移速翻倍，可正常移动 / 冲刺 / 二段跳，攻击只能用 `J` 瞬发拳——没有前后摇、每拳 8 伤害、不回复能量，狂按 J 就是最高输出；时停内对手只掉血并正常获得受击能量，不累积硬直、不被击飞；时停期间把对手打倒会立即结束时停并判胜。演出为时停生效瞬间全屏压暗并在底部显示剩余秒数、恢复时碎裂特效。
- **时停飞刀（迪奥布兰达）**：时停中按 `U` 每 0.22 秒掏出一把飞刀，最多 8 把，全部悬停在身前不动、不结算伤害；时间恢复的瞬间一起射出（每把 6 伤害，格挡只吃 1 点擦伤）。四档高度循环分布（46 / 78 / 112 / 148），蹲姿头顶只有 118，所以蹲下也会吃到三把，躲不干净。掏刀和 MUDA 连打共用同一段时间，想齐射就得放弃那几秒的拳数——它换来的是必定命中的远程收尾。
- **ROAD ROLLER DA!!（迪奥布兰达）**：时停中用 `J` 打中 5 拳后，`K` 触发压路机砸下：造成 65 伤害并击倒 1.8 秒，砸下瞬间时间立即恢复（悬停的飞刀同时齐射），迪奥自身有 26 帧收招，砸完会被对手惩罚。5 拳门槛只认真正落地的拳，空挥不计。
- **气化冷冻法（迪奥布兰达）**：`A/D + L L` 消耗 30 能量，抬手 14 帧后 4 帧有效、收招 20 帧，向前射出一段蓝色冰束。冰束是飞行道具（900 像素/秒、存活 0.42 秒，从身前约 62 像素处射出，实际起手距离约 480 像素），命中造成 12 冻伤并把对手原地冻结 1.5 秒（期间无法移动 / 出招 / 跳跃）。它走投射物判定，所以**站立防御能挡下**（只吃 1/5 擦伤、不冻结），**蹲下可以从下方让过去**——换来的是中距离起手能力。冻结中挨到的第一记干净命中额外承受 30 点「碎裂」伤害并提前破冰，冻结硬直同时回落到这一击本身的受击帧数，所以这 30 点是用剩余冻结时间换来的。命中返还一半能耗（15 点，空放照扣）——满能量打完剩 85，还要再攒 15 点才能进时停，所以这套冻结是压血与走位工具，不是大招启动键。对**已经冻住**的对手再打中冰束不会续冻，否则 0.42 秒一发就能把冻结永久续下去。
- **二段跳**：首次跳跃落地前再按一次 W / 空格可追加一段跳跃，落地后重置。
- **冲刺**：双击前 / 后方向触发前冲或后撤，冲刺时有残影尘土。
- 每个角色在 `characters.py` 中拥有独立的血量、移动速度、小技能、大招与专属连招数据；目前连招以命中取消 + 单键输入缓存衔接与抓取追打为主，冷静的普通人的大招已接入“双击方向 + 连按攻击键”的方向指令，更长的指令串（如 ↓↘→ 之类）尚未实现。
- UI 演出：页面淡入切换、按钮悬停缓动、战斗页全屏沉浸渲染（竞技场铺满 1210×680 整个画布：背景图 cover 铺满天空区、聚光灯锥与立柱推到画布两缘、地面渐变延伸到画布底；战斗地面线保持原位，手感与 AI 距离感不变）、HUD 贴顶叠加（血条 / 能量 / 计时器压在场景上层，不再有顶部标题栏与左下角退出按钮）、血条平滑掉血（含延迟白色损血条）、加粗能量条（大招可放时变金色微光）、连击 HIT 计数、血条下方信息分两排（上排玩家名 + 右对齐 `HP 当前/上限`，下排角色名 + 右对齐 `能量 数值`；练习模式下 AI 名显示为「普通AI / 中等AI / 困难AI / 地狱AI」并按难度着色，联机长昵称自动截断防溢出）、每回合 3 秒倒数与 `FIGHT!`、回合 `ROUND / FIGHT / K.O.` 横幅、命中定格、火花与落地扬尘粒子、低血量闪红计时。愤怒的普通人的大招有完整专属演出：起手时火焰向身体收缩聚能、三道火焰螺旋把对手卷到面前、每段拳击迸发火焰尖刺与余烬（末段加重）、甩飞时留下火焰拖尾并在落点炸出冲击环与扬尘，配合 `KNOCKDOWN 2s` 飘字；音效为独立的吸取、连击、终结拳与重投掷四段。专属连招释放时双拳燃起火焰并持续闪烁，冷静的普通人的突进大招每次斩击都有斜向刀光与专属冰手里剑命中音效。
- 战斗中 ESC 打开暂停菜单（模式说明 + 继续 / 设置 / 重新开始 / 返回主菜单）；「设置」直接复用设置页，可随时开关音乐音效、切换全屏并查看招式表（AI 难度与角色风格已在开局锁定，此处改档只在下一局生效），返回后回到仍处于暂停的对局；联机对局中 ESC 直接退出回房间，避免本地暂停造成不同步。

### 石面鬼之眼（引导型定点激光）

迪奥布兰达的旧远程技能，已被「飞刀」替换。它是一个"按住不放的定点炮台"：不移动、不飞行、瞬间命中，与飞行道具是两条完全不同的代码路径。

| 配置字段 | 值 | 说明 |
| --- | --- | --- |
| `style` | `"laser"` | 战斗核心据此把远程键分派给 `_tick_laser`，而不是生成飞行道具 |
| `damage` | `12` | 每次判定伤害 |
| `speed` | `0` | 不是飞行道具，恒为 0 |
| `lifetime` | `0.5` | 仅为兼容投射物字段，激光不走存活计时 |
| `length` | `430` | 光柱射程，超出场地边界会被截断 |
| `tick_interval` | `0.5` | 首次命中后每隔这么久再结算一次 |
| `color` / `size` | 血色 / `5` | 光柱颜色与粗细 |

机制规则：

- 起手 `LASER_STARTUP`（12 帧）后光柱才出现，收招 `LASER_RECOVER`。
- 引导期间不能移动；松手、被打断、离地都会立即收束并进入收招，同时发出 `laser_end` 事件。
- 按住 `S` 会从更低的眼睛位置射出（`LASER_CROUCH_EYE_HEIGHT`），因此可以打到蹲着的对手。
- 伤害不累积硬直、不击飞、不打断对手动作，是纯粹的定点消耗。
- 首次碰到立刻结算一次，之后按 `tick_interval` 周期结算。

实现落点（改角色前先看这几处）：

| 文件 | 位置 | 作用 |
| --- | --- | --- |
| `fighter/combat.py` | `_press_kind` 的 `style == "laser"` 分支 | 把 `U` 分派成 `attack_kind = "laser"` |
| `fighter/combat.py` | `_tick_laser` | 起手、引导、周期结算、收束 |
| `fighter/combat.py` | `LASER_*` 常量 | 起手 / 收招 / 眼睛高度等全部参数 |
| `fighter/arena.py` | `draw_laser` | 光柱与眼睛高光绘制 |
| `fighter/ui.py` | `laser_end` 事件 | 收束音效与视觉 |
| `fighter/ai.py` | `_shot_reach` | `style == "laser"` 时用 `length` 当射程（不能用速度 × 存活） |
| `fighter/ai.py` | `_shot_keys` | 激光不分高低弹道，永远只按 `projectile` |

启用方式：给角色加

```python
"projectile": {"name": "…", "damage": 12, "speed": 0, "lifetime": .5,
               "color": (214, 24, 46), "size": 5,
               "style": "laser", "length": 430, "tick_interval": .5},
```

注意：飞行道具的 `length` 是刀身 / 光柱的视觉长度，不要拿它当射程。AI 判断远程距离时，引导型激光读 `length`，其余飞行道具按 `speed × lifetime` 计算。

## 进一步增加角色 / 技能

- `fighter/characters.py` 的 `CHARACTERS` 定义角色血量、移动速度、配色、装饰、远程攻击、大招与专属连招。新增角色后会自动出现在选角界面；战斗核心通过 `Combat.set_loadout()` 应用这些数值，回合切换时会保留角色配置与能量。

- `fighter/arena.py` 的 `MAPS` 用纯数据定义舞台（当前有 `dojo`「原初战场」与 `lava`「熔岩地貌」，`config.py` 的 `map` 键记录选择）；舞台可选 `bg`（铺满舞台的背景图）和整套配色，新增舞台只需加一条字典，渲染层无需改动。熔岩火柱机关在 `combat.py` 的 `_tick_map_hazards` 中实现，联机时由房主权威结算并随快照同步。

## 技术边界和待办

- 当前火柴人是程序化关节点姿势，不是逐帧精修的骨骼动画；没有关键帧时间轴、IK、图形编辑器和装饰物完整物理模拟。攻击动作已按起手 / 有效 / 收招帧在姿势之间做缓动插值。
- 当前 hitbox 还是可配置的距离与高度范围，尚未构建独立可视化矩形盒碰撞编辑器；高级防御、空连、霸体与 MK 式多段连段串（Dial-a-Combo）也未完成。
- 远程攻击已是独立运动的飞行道具实体，但命中判定仍为矩形近似，且暂不支持弹反、多段或追踪。
- AI 难度分四档：面对 AI 的对手档位在设置页「AI 难度与角色风格」区的芯片中点选，AI 对打两侧档位在主菜单 P2 角色卡上方的两枚芯片里直接点选（点一下前进一档），难度键分别为 `normal / medium / hard / hell`（旧存档的 `hard`/`expert` 会自动迁移，`ai_level_p1` / `ai_level_p2` 缺省时沿用 `ai_level`）。普通难度按对手血量切换打法：对手血量高时以远程弹幕牵制（高低波混发），血量低时主动压上打连招；中等难度不再看血量，而是自行判断局面（惩罚硬直 / 挥空、对手举盾时贴身抓取或下段、能量满时逼近放超杀、自己残血时拉开距离）；困难难度判断更果断，并且能量足够、对手又在大招命中范围内时当帧立刻释放大招。地狱难度在全知视角下读对手出招帧——抓取起手后撤、挥空期间前压、收招帧帧级反打，且闪避 / 放超 / 投弹概率全部为 1（绝不失误）。对手倒地时先后撤（含双击后撤冲刺）拉开距离，等其起身再用远程攻击追击。AI 也会下蹲躲避高位弹道、在连段后拉开距离，并修复了出招卡顿（按键保持跨物理帧、过期指令自动放弃）；抓取与下段技的出招距离已与命中判定对齐，不会在蹲防面前空挥；仍不会主动跳跃。
- AI 防止无限防守：若连续一段时间（普通 4 秒 / 中等 2.8 秒 / 困难 2.2 秒 / 地狱 1.4 秒）只是在防御或后退，会强制进入 1.6 秒“主动压上”状态——取消防御与后撤，无视来弹，径直逼近对手并出手，之后重新计时。命中对手会立即清零该计时。

### 架构与可维护性

- **`fighter/ui.py` 仍是集中式的 `GameApp` 外壳**：单文件 1032 行，页面（菜单 / 选角 / 角色展示 / 设置与招式表 / 联机连接与房间）已拆到 `fighter/pages/`，战斗渲染已拆到 `fighter/arena.py`；但页面路由、战斗流程、按键采集、特效与网络轮询仍集中在 `GameApp`，各页面以 mixin 形式直接读写宿主状态。建议进一步把应用流程（`run` / `set_page` / `poll_network` / `apply_combat_event`）与渲染、输入分层，并把特效与 HUD 绘制进一步模块化。
- **特殊技状态机硬编码在战斗核心**：`combat.py` 里 `_tick_grab_super` / `_rush_super` / `_tick_ice_shadow` / `_spawn_strike` 等为每个角色的专属技能写死了独立的状态机（`pummel_state`、`rush_done`、`shadow_*` 常量等）。这与 `characters.py` 中「新增角色无需改动战斗逻辑」的声明相矛盾——新增一个带自定义演出的角色仍需改动 `combat.py`。建议把特殊技抽成可插拔的「行为组件 / 招式脚本」（每个技能自带 `on_start/on_tick/on_hit/on_finish`），战斗核心只调度。
- **角色状态用散字典 + 字符串键**：`fresh_fighter()` 返回的 dict 使用 `f['cancel_left']`、`f['rush_done']`、`f['pummel_frame']` 等大量字符串键读写。键名拼错会静默产生错误行为而无任何报错，且无类型约束。建议改为 `@dataclass FighterState`（或 TypedDict），把字段与默认值集中定义，用属性访问替代字符串索引。
- **魔法数字分散**：`combat.py` 与 `characters.py` 都堆叠几何 / 帧数据（如 `_rush_super` 中 `victim['x'] + side * 54`、近身推挤 `48/75`、`GRAB_PULL_DISTANCE=54` 等）。建议统一集中到 `config.py` 或 `constants.py`，并按「身体坐标常量」命名（项目记忆里已强调过远程弹道需统一坐标常量，但当前仍有零散字面量）。
- **指令解析重复且绕**：大招判定里 `double_tap_punch` / `double_tap_kick` / `double_down` 三个分支在 `_tick` 内联手写，与 `_command_prefix`、`input_buffer.py` 的 `double_press/double_tap_recent/double_down` 职责重叠，改一处容易漏一处。建议在 `InputBuffer` 内统一实现一个 `command(command_spec)` 解析器，由 `characters.py` 的配置驱动。
- **保留的未调用辅助 API**：`assets.full_body()`（与 `portrait()` 对称的全身图入口）、`assets.clear_cache()`（开发期替换素材后的缓存清理）、`InputBuffer.double_up()`（W,W 指令预留，当前无角色使用）三个符号在项目内没有调用点。它们不影响运行，保留作为扩展点；若确认不再需要，可一并删除，避免读代码时误以为有隐藏调用方。

### 正确性风险

- **`body_span` 未把 `crouch_guard` 视为蹲姿**（[combat.py](file:///e:\py project\LAN_Fighter_3.0\fighter\combat.py#L112-L116)）✅ **已修复**：`body_span` 原用 `action == 'crouch'` 而非 `crouching()`，导致**蹲防**时弹道碰撞盒按站立身高计算，与 `crouching()`（含 `crouch_guard`）不一致。现已改为复用 `crouching(fighter)`，并补充 `BodySpanTests` 回归测试。
- **网络层无回滚 / 预测 / 输入序列号**（README「技术边界」已列为待办）：TCP 无帧号与去重，丢包或抖动时客户端直接采用最新快照，可能出现瞬时跳变。建议至少为输入与快照加入帧序号，中远期引入回滚网络（rollback netcode）。
- **`network.py` 存在死代码** ✅ **已修复**：`RoomServer._new_fighters()` 定义后从未被调用（真实战斗用 `combat.fighters`），现已删除。
